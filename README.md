# Что приготовить?

Небольшое веб-приложение на JavaScript: React и Vite на клиенте, Express на сервере. Пользователь указывает продукты и кухонную технику, Gemini предлагает рецепт и генерирует фото готового блюда.

Ключ API хранится только в `.env` и не попадает в браузер.

## Запуск

```bash
npm install
```

Скопируйте `.env.example` в `.env` и вставьте свой ключ:

```
GEMINI_API_KEY=ваш_ключ
```

Запустите клиент и сервер:

```bash
npm run dev
```

Откройте [http://localhost:5174](http://localhost:5174). Запросы к `/api` проксируются на порт `3002`.

## Деплой на Vercel

В проекте Vercel задайте переменную окружения `GEMINI_API_KEY`. При необходимости можно также задать `GEMINI_MODEL` и `GEMINI_IMAGE_MODEL`.

Фронтенд собирается Vite, а маршруты `/api/recipe`, `/api/image` и `/api/health` работают как серверные функции. Ключ по-прежнему остаётся только на сервере.

## Что умеет

- Поле продуктов и выбор техники
- Название блюда, ингредиенты, шаги, время и примерная калорийность на порцию
- Изображение примерного вида готового блюда. Если у ключа нет квоты на фотомодель, Gemini рисует иллюстрацию.
